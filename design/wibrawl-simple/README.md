# Wibrawl — simplified symbol

Two rounded, offset hooks form one compact interlocking mark. The design uses broad strokes and an open centre, with no wordmark, initials, mascot, sports equipment or controller.

Neon blue `#00C8FF` and neon pink `#FF3096` carry the two forms. A small yellow `#F4FF38` accent sits at one end. The single-colour versions preserve the same silhouette and spacing.

- `wibrawl-simple.svg`: transparent full-colour master.
- `wibrawl-simple-white.svg`: single-colour white master.
- `wibrawl-simple-black.svg`: single-colour black master.
- `preview.png`: presentation preview on a dark background.
- `applications.png`: light, dark, single-colour and small-size previews.
- `build.mjs`: original source geometry; run with `node design/wibrawl-simple/build.mjs` from the repository root using the project's Sharp dependency.

The SVGs consist only of filled paths. They require no fonts, linked resources, raster images, filters or masks. Preserve the square viewBox and aspect ratio when scaling. Earlier proposals remain in their original folders for history.
