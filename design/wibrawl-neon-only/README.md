# WiBrawl — neon-only WB

The approved Shift and Flow outlines recoloured entirely in neon colours:

- Neon yellow `#DDFF39`: dominant letter colour, close to the website's lime family.
- Electric blue `#246BFF`: secondary detail and an edge on Sports variants.
- Neon pink `#FF3BB5`: a small detail, substantially less prominent than yellow.

The logo artwork contains only these three colours. Counters and backgrounds are transparent. Neutral colours in the presentation belong to the website UI, not to the logo.

Website background, ink, surface, line and accent colours are taken from `react-app/src/wibrawl.css`. Gaming uses `#101413`; Sports uses `#F4F6EF`. The Sports variants add an electric-blue edge to support yellow on the pale background.

`website-theme-comparison.png` contains static header mockups and enlarged marks in both themes. These are design previews, not screenshots of a deployed website. `applications.png` includes small-size studies.

The SVG masters are:

- `wibrawl-shift-gaming.svg`
- `wibrawl-shift-sports.svg`
- `wibrawl-flow-gaming.svg`
- `wibrawl-flow-sports.svg`

Run `node design/wibrawl-neon-only/build.mjs` from the repository root. The generator reads the approved outlines from `design/wibrawl-neon-wb` and preserves their geometry.

These are proposals; neither logo has been installed in the website or undergone trademark clearance.
