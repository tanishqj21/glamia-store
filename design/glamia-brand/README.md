Glamia vector artwork
=====================

The ribbon G is traced from the existing Glamia artwork. All geometry is vector paths; no bitmap is embedded. The LAMIA lettering is outlined from Cormorant Garamond at weight 400 with the existing storefront proportions and tracking. Its SIL Open Font License is included.

`g.svg`: symbol and browser favicon. `logo.svg`: dark lettering. `logo-light.svg`: light lettering. `lettering.svg`: currentColor outlines for the website. Run `node scripts/prepare-glamia-brand.mjs` to distribute these masters to the website and native apps. Native launcher PNGs are generated from the SVG source because platform launchers require raster icons.
