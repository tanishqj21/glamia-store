# Wibrawl — WB Rush

An arrow-led revision of the WB idea. The primary silhouette sweeps upward to the right. Its double-bend tail borrows the W's rhythm; two cutouts in the rising head reference the B's counters. The initials are abstract references, rather than a typographic WB lockup.

The uneven bends, clipped corners and broad head are intended to bring movement and a more expressive streetwear character to the mark.

## Deliverables

- `logo-preview.png`: enlarged silhouette

- `build.mjs`: reproducible geometry and previews

One filled compound path with transparent counters; no fonts or embedded raster artwork.

Run `node design/wibrawl-wb-rush/build.mjs` from the repository root.
